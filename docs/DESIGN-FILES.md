# Preparing designs for "Personalise this design"

Customers type their names, dates and photos onto your design and see it live, on a table or
desk scene, and over their own camera. This page explains how to prepare the files.

## Best: upload the PSD

Admin → Designs & prices → open the design → **Personalise** → **Upload PSD, JPG, PNG or SVG**.

The site reads the Photoshop layers:

| In Photoshop | Becomes |
|---|---|
| A **text layer** (live text, not rasterised) | A box the customer fills in, at the same place, size and colour. The layer name becomes the label ("Bride name"). The text in it becomes the sample. |
| A text layer whose name contains **date** | A date box (English, Tamil or both). |
| A layer named **photo** (or `photo circle`) | A photo frame. Draw it as a shape covering the area; it is left out of the background. |
| Every other visible layer | Painted into the background. |

Checklist for each PSD:

- Keep names, dates, venue, company name, phone and any wording as **live text layers**.
  Rasterised or converted-to-shape text stays in the background and cannot be changed.
- Name the text layers clearly: `Bride name`, `Groom name`, `Wedding date`, `Venue`, `Company`.
- Merge layers that use special blend modes (multiply, overlay) or effects into normal
  layers. The site shows every layer as normal.
- Size: 1500–3000 px wide is ideal. Larger files work but take longer to read.
- Smart objects: rasterise them, or merge them into a normal layer.

After uploading, check the boxes, adjust size, style and colour if needed, and **Save**.

## Also fine: JPG, PNG or SVG

Export the design with the name, date and photo layers **hidden**, then upload it and add
boxes with the one-click buttons (+ Bride's name, + Event date, + Photo…).

## Fonts

Photoshop fonts are matched to the closest web font: script fonts → Great Vibes, serif →
Playfair Display, capitals → Cinzel, Tamil → Mukta Malar, everything else → Poppins.
Send the font names you use and they can be matched more closely.

## Which design gets which template

Each template belongs to one design (its product code, e.g. ZD-014). To reuse a layout on
another design, open that design and upload the same file.
